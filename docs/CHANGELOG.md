# FileView 更新日志

本文件汇总 FileView 各版本的变更要点，是**版本控制的唯一索引**。
每个版本的详细说明见 `docs/` 下的三件套：

| 文件 | 内容 |
|---|---|
| `PLAN-vX.Y.Z.md` | 需求计划：问题 → 目标形态 → 功能需求 → 验收标准 → 实施结果 |
| `RELEASE-vX.Y.Z.md` | 发行说明：新增 / 改进 / 修复 / 升级提示 / 下载 |
| `AUDIT-vX.Y.Z.md` | 代码审核报告：审核方法、已修复缺陷、遗留问题、变更清单 |

命名约定：`{PLAN,RELEASE,AUDIT}-v{主}.{次}.{修订}.md`，与 `package.json`、
`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json` 的版本号严格一致。
新版本发布时三份文档必须齐备，缺一视为版本控制不完整。

## v0.2.2 — 2026-11-22

**修复 Markdown 换行与选中重影，补齐版本控制文档。**

### ✨ 新增

- **Markdown 渲染器结构化重写**（`src/lib/markdown.ts`）
  - 引用块内容递归解析：块内的段落、空行分段、列表、代码块全部保留结构，
    不再被压成一整行；
  - 硬换行：行尾两个空格或反斜杠 → `<br />`；
  - 缩进嵌套列表、任务列表（`- [ ]` / `- [x]`）；
  - Setext 标题（`===` / `---` 下划线式标题）；
  - 反斜杠转义（`\*`、`\_`、`\[` 等按原样输出）；
  - CRLF / CR 行尾统一规范化为 LF，不再残留 `\r`。
- **相对链接可用**：`README.md`、`docs/START-HERE.md` 这类同目录文档链接
  保留有效 `href`，不再一律降级为 `#`。
- **版本控制文档体系**：`CHANGELOG.md`（本文件）、`docs/README.md`（文档索引）、
  v0.2.2 的 PLAN / RELEASE / AUDIT 三件套。

### 🛠️ 改进

- **Markdown 列表重新显示标记**：Tailwind 的 preflight 会把 `ul` / `ol` 重置为无标记，
  预览里的列表项此前没有任何项目符号 / 序号；现已恢复 `disc` / `decimal`。
- **Markdown 相对链接可点击**：相对路径链接此前是死链接，现按当前文档所在目录
  解析后在应用内直接打开（`../` `./` 与 URL 编码均支持）。
- **Markdown 链接地址不再被双重转义**：`?a=1&b=2` 里的 `&` 之前会变成
  `&amp;amp;`，导致链接失效；现已只转义一次。
- **表格识别更严格**：分隔行列数必须与表头一致，避免把普通段落误判成表格。
- **编辑器选中不再出现重影**：透明编辑层在选中时会把文字重画一遍，
  与下方的语法高亮层叠成「虚影」；现强制选中文字保持透明，只留选中底色。
- **制表位对齐**：高亮层与编辑层的 `tab-size` 统一为缩进设置值，
  含 Tab 的文件不再出现横向错位。

### 🐛 修复

- 引用块内的多行说明被合并成一行、列表被降级为普通文本（**主要问题**）。
- CRLF 结尾的 Markdown 在段落 / 列表中残留 `\r`，导致行尾出现异常空白。
- 相对链接全部指向 `#`，点击无反应。
- 代码审核另修复 22 项缺陷，其中 4 项会造成数据丢失
  （分离标签丢未保存修改、格式化写到别的标签、大文档批量替换损坏文件、
  重开未保存文件覆盖内存文本）。
  完整清单与遗留问题见 [`AUDIT-v0.2.2.md`](./AUDIT-v0.2.2.md)。

### 📦 其它

- 版本号升级至 **0.2.2**（`package.json` / `Cargo.toml` / `tauri.conf.json` /
  `Cargo.lock` / 关于对话框 / 设置页 / README 下载链接）。
- 测试：前端 46 → **68 项**，后端 49 → **64 项**。

## v0.2.1 — 2026-11-17

**工具栏以「眼睛」按钮取代查看工具；Markdown / HTML 打开即预览；Notepad++ 式搜索。**

### ✨ 新增

- **Notepad++ 式搜索**：命中在文档中高亮（当前命中加深）、查找 / 替换词历史下拉回选、
  区分大小写、替换 / 全部替换（`Ctrl+F` / `Ctrl+H`）、`Enter` 逐处跳转、`F3` 下一处。
- **文件夹搜索**（`Ctrl+Alt+F`）：递归搜索目录，底部「搜索结果」窗口列出
  全部命中（文件 + 行列 + 原文），点击即跳转定位，并可批量替换。
- **工具栏「眼睛」预览按钮**：一键打开当前文件大类的默认视图
  （Markdown / HTML → 预览，JSON → 树形，CSV → 表格，配置类 → 结构）。

### 🛠️ 改进

- 刷新（webview reload）后按会话快照恢复已打开的文件与面板状态。
- 预览面板默认占窗口一半，可拖拽调宽。
- 查找栏输入时不再被编辑器抢走焦点（避免查找词被插入正文）。
- 查找栏可开合（`Ctrl+F` 再次按下即收起，并一并关闭底部结果窗口）。

### 🐛 修复

- 分离标签后空白页不再挂着上一个文档的预览窗口。
- 预览面板的关闭按钮不再误关查找栏。
- 工具栏提示气泡被裁切。

## v0.2.0 — 2026-10-26

**Notepad++ 风格重构：文档区恒为文本，查看能力收进可停靠工具面板。**

- 面板化布局：文档区唯一，树形 / 表格 / 预览 / 结构 / 大纲 / 原始收进右侧面板。
- 多格式支持（60+ 扩展名）：JSON 家族、Markdown、INI/properties、YAML、TOML、
  CSV/TSV、XML/HTML、20+ 代码家族、日志与文本。
- 文档内查找（`Ctrl+F`）、撤销 / 重做（`Ctrl+Z` / `Ctrl+Y`，600ms 合并）。
- 语法高亮扩展至 YAML / TOML / CSV / XML / HTML + 20+ 代码家族。
- 详见 [`RELEASE-v0.2.0.md`](./RELEASE-v0.2.0.md) 与
  [`AUDIT-v0.2.0.md`](./AUDIT-v0.2.0.md)（含 14 项安全与正确性缺陷的修复记录）。
