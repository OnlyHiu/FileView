# FileView v0.2.2

**修复 Markdown 预览「无法正确换行分行显示」与「选中文字虚影重叠」两个用户可见缺陷；补齐版本控制文档体系；并完成一轮前后端全量代码审核。**

发布日期：2026-11-22 · 上一版本：v0.2.1

---

## 🐛 修复（用户反馈）

### Markdown 预览无法正确换行分行显示

**现象**：文档中的引用块（`>`）在预览里被压成一整段——标题、列表条目全部挤在同一行，
引用块里的 `-` 列表项退化成普通文本。

**根因**：`renderMarkdown()` 把连续的引用行用 `quote.join(" ")` 拼成**单个段落**输出，
引用块内部**不递归解析**，列表 / 代码块 / 空行分段全部丢失。

**修复**：块级解析统一收敛到 `renderBlocks()`，引用块内容递归交给它处理：

| 场景 | 修复前 | 修复后 |
|---|---|---|
| `> **新手导读**` + `>` + `> - 条目` | 一整段文字 | 段落 + 列表（每条一行）|
| 引用块内的代码块 | 退化成文本 | `<pre>` 代码块 |
| 引用块内的空行 | 被吞掉 | 正确分段 |

同时补齐的换行语义：

- **硬换行**：行尾两个空格或反斜杠 → `<br />`；
- **引用块按源文件分行**：引用块常被当作「提示框」，一行一条说明，
  因此块内保留源文件换行（不按 CommonMark 的软换行合并）；
- **缩进嵌套列表**、**任务列表**（`- [ ]` / `- [x]`）；
- **Setext 标题**（`===` / `---` 下划线式标题）；
- **反斜杠转义**（`\*`、`\_`、`\[` 等按原样输出）；
- **CRLF / CR 行尾统一为 LF**：段落与列表中不再残留 `\r`（此前 CRLF 文件行尾会出现异常空白）。

### 选中文字出现「虚影重叠」

**现象**：在文档区选中一段文字后，选中区域里出现两层重叠的文字。

**根因**：文档区是「透明 textarea + 语法高亮层」叠加显示。
选中时浏览器按系统 `::selection` 用**不透明前景色**重绘选中文字，
透明文字因此变得可见，与下方高亮层的文字叠在一起。

**修复**：`.editor-surface::selection` 强制选中文字保持透明
（`color` + `-webkit-text-fill-color`），只保留半透明选中底色，
高亮层文字透过底色正常显示；底色随深浅色主题切换。

### 相对链接全部失效

`[README.md](README.md)` 的 `href` 此前一律降级为 `#`（相对路径正则只接受
`#` / `/` / `./` / `../`）。现已放行普通同目录文档链接，
`javascript:` / `data:` / `vbscript:` / 协议相对地址 `//host` 仍被拦截。

### 链接地址里的 `&` 被双重转义

`?a=1&b=2` 此前渲染成 `?a=1&amp;amp;b=2`，链接实际指向错误地址。
现已只转义一次。

## 🛠️ 改进

- **Markdown 列表重新显示标记**：Tailwind 的 preflight 会把 `ul` / `ol` 重置为
  无标记，预览里的列表项此前没有任何项目符号 / 序号；现已恢复 `disc` / `decimal`。
- **Markdown 相对链接可点击**：`[README.md](README.md)` 这类相对链接此前是死链接，
  现按当前文档所在目录解析后在应用内直接打开（`../` `./` 与 URL 编码均支持）。
- **表格识别更严格**：分隔行的列数必须与表头一致，
  避免把「普通段落 | 另一段 + `---`」误判成表格。
- **含 Tab 的文件不再横向错位**：高亮层与编辑层共用同一个 `tab-size`
  （取自缩进设置：`2` / `4` / `tab`）。
- **版本控制文档体系**：
  - 新增 [`docs/CHANGELOG.md`](./CHANGELOG.md)：全部版本的变更汇总，作为版本控制的唯一索引；
  - 新增 [`docs/README.md`](./README.md)：文档索引 + 写作规范 + 发版检查清单；
  - 新增 `PLAN-v0.2.2.md` / `RELEASE-v0.2.2.md` / `AUDIT-v0.2.2.md` 三件套；
  - 补齐缺失的 `RELEASE-v0.2.1.md`。

## 🔍 代码审核（详见 [AUDIT-v0.2.2.md](./AUDIT-v0.2.2.md)）

本轮对前端 20 个文件、后端 11 个文件做了全量审核，共修复 **22 项主要缺陷**
（另有若干低优先级改进一并处理），其中 4 项会造成数据丢失：

| # | 问题 | 影响 |
|---|---|---|
| 1 | 分离标签时未保存的修改被丢弃 | **数据丢失**：新窗口读到磁盘旧内容，主窗口随后关闭原标签 |
| 2 | 格式化 / 压缩 / 排序写到别的标签 | **数据丢失**：切换标签期间执行会把 A 的内容写进 B |
| 3 | 大文档「全部替换」用旧命中位置改文档 | **文件损坏**：防抖窗口内命中未重算，偏移与词长不匹配 |
| 4 | 重新打开已有未保存修改的文件 | **数据丢失**：磁盘内容直接覆盖内存文本 |

其余修复覆盖：解析结果串档、搜索命中错位、设置项连点丢失、
批量替换大小写口径不一致、批量替换静默失败、Esc 层级冲突、
JSONL 一行坏就整体不可格式化、搜索命中偏移口径不一致、
注册表清单并发写坏、单个非法扩展名导致所有关联注册不上、
能力表被外部清理后无法自愈、旧品牌迁移每次启动都跑、
设置文件单个字段类型错误导致整份配置被重置等。
