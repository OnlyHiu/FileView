# FileView v0.2.1

**工具栏以「眼睛」按钮取代查看工具；Markdown / HTML 打开即预览；新增 Notepad++ 式搜索（查找 / 替换 / 文件夹搜索）。**

发布日期：2026-11-17 · 上一版本：v0.2.0

---

## ✨ 新增

### Notepad++ 式搜索

- **文档内查找**（`Ctrl+F`）
  - 查找栏浮出在文档区顶部：匹配计数（`3/12`）、上一个 / 下一个（`F3` / `Shift+Enter`）、
    区分大小写（`Aa`）、`Esc` 关闭；
  - 命中在文档中高亮，**当前命中加深**，其余命中淡黄；
  - 命中数随编辑实时重算（偏移同步，不会指向过期位置）。
- **替换**（`Ctrl+H`）
  - 替换行可展开，`Enter` 替换当前命中，`全部替换` 一次性替换所有命中；
  - 替换词与查找词各自保留历史（`localStorage`），下拉可回选。
- **文件夹搜索**（`Ctrl+Alt+F`）
  - 递归搜索整个目录，底部「搜索结果」窗口列出全部命中
    （文件 + 行列 + 原文），点击即跳转定位；
  - 支持对搜索结果批量替换。

### 工具栏「眼睛」预览按钮

- 取代原先的「查看工具」按钮：一键打开当前文件大类的**默认视图**
  （Markdown / HTML → 预览，JSON → 树形，CSV → 表格，INI / YAML / TOML → 结构，
  XML → 标签树，代码 → 大纲）；
- 再次点击收起面板。

---

## 🛠️ 改进

- **刷新后恢复会话**：webview 刷新（右键菜单「刷新」）后按会话快照恢复
  已打开的文件、活动标签、面板与视图状态，不再一片空白。
- **预览面板默认占窗口一半**（可拖拽调宽），与「文档区唯一」的布局理念一致。
- **查找栏不再抢焦点**：查找栏输入时不会把焦点夺回编辑区，
  避免查找词被误插入正文。
- **查找栏可开合**：`Ctrl+F` 再次按下即收起，并一并关闭底部搜索结果窗口。
- 工具栏提示气泡不再被裁切。

---

## 🐛 修复

- 分离标签后，空白页不再挂着上一个文档的预览窗口。
- 预览面板的关闭按钮不再误关查找栏；关闭查找时同步收起结果窗口。

## ⌨️ 常用快捷键

| 功能 | 快捷键 |
|---|---|
| 新建 / 打开 / 保存 | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` |
| 另存为 / 关闭标签 | `Ctrl+Shift+S` / `Ctrl+W` |
| 查找 / 查找下一个 | `Ctrl+F` / `F3` |
| 替换 | `Ctrl+H` |
| 文件夹搜索 | `Ctrl+Alt+F` |
| 格式化 JSON | `Ctrl+Shift+F` |
| JSONPath 查询面板 | `Ctrl+G` |
| 查看工具面板 | `Ctrl+B` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
