# FileView v0.2.0

**Notepad++ 风格重构：文档区恒为文本，查看能力收进可停靠工具面板；新增多格式支持、文档内查找与撤销/重做。**

发布日期：2026-10-26 · 上一版本：v0.1.0

---

## ✨ 新增

### 多格式支持（60+ 扩展名）

| 类型 | 扩展名 | 视图 |
|---|---|---|
| JSON 家族 | `.json` `.jsonc` `.json5` `.jsonl` `.ndjson` `.har` `.geojson` `.webmanifest` | 树形 / 表格 / 原始 |
| Markdown | `.md` `.markdown` `.mdown` | 预览 / 源码 |
| 配置 | `.ini` `.cfg` `.conf` `.config` `.properties` `.env` `.yaml` `.yml` `.toml` | 键结构 / 源码 |
| 数据 | `.csv` `.tsv` | 表格（自动识别分隔符，支持引号转义）|
| 标记语言 | `.xml` `.svg` `.html` `.htm` `.vue` `.svelte` | 标签树 / 沙箱预览 / 源码 |
| 代码 | `.js` `.ts` `.jsx` `.tsx` `.py` `.rs` `.go` `.java` `.cs` `.cpp` `.c` `.h` `.php` `.rb` `.sh` `.ps1` `.sql` `.css` 等 | 符号大纲 / 源码 |
| 日志 / 文本 | `.log` `.txt` `.text` | 级别与时间戳着色 |

- 新增语法高亮：YAML / TOML / CSV / XML / HTML，以及 20+ 代码家族（JS·TS·Python·Rust·Go·Java·C#·C++·Kotlin·Swift·PHP·Ruby·Shell·PowerShell·SQL·Lua·Dart·CSS）的关键字、类型、函数与内置常量着色。
- 新增视图：CSV/TSV 表格视图、YAML/TOML 键路径结构视图、XML 标签树视图、HTML 沙箱预览、代码符号大纲。
- 文件关联（默认打开方式）与右键菜单注册扩展名同步扩展。

### 文档内查找（`Ctrl+F`）

- 文档区顶部浮出查找栏：匹配计数（`3/12`）、上一个 / 下一个（`F3` / `Shift+Enter`）、区分大小写（`Aa`）、`Esc` 关闭。
- 命中处直接选中并滚动定位，不打断编辑；文档内容或标签切换后自动重算命中位置。

### 撤销 / 重做（`Ctrl+Z` / `Ctrl+Y`）

- 每标签独立历史栈，最多 200 步，600ms 内连续输入自动合并为一步。

### 其它

- 「格式化」菜单新增**字符串转义 / 反转义**与**解析模式**切换（严格 JSON / JSONC / JSONL）。
- 工具栏新增查看工具开关（`Ctrl+B`）、查找、撤销、重做按钮；标题栏显示当前文件完整路径。

## 🛠️ 改进

- **布局重构**：标题栏 → 菜单栏 → 工具栏 → 标签栏 → 文档区（+ 右侧工具面板）→ 状态栏，节奏与留白按 Notepad++ 骨架重排，整体观感更精致。
- **文档区唯一**：不再有「编辑器 / 查看器」二选一，文档区始终显示当前文件文本（行号、语法高亮、当前行高亮、错误行标注），可随时编辑保存。
- **查看器工具化**：树形 / 表格 / 预览 / 结构 / 大纲 / 原始视图统一收进右侧「查看工具」面板，面板宽度可拖拽调整。
- **面板化设置与查询**：设置面板、JSONPath 查询面板同样以停靠面板呈现，文档区不再被覆盖。
- 状态栏补充编码（UTF-8）、文件类型与完整路径；标签页激活态增加强调条；暗色主题语法配色重新调校。

## 🐛 修复

- **修复点击「设置」后覆盖文本显示区域**：设置界面改为右侧不透明停靠面板，与文档区并存、可关闭（× / `Esc` / 菜单切换）。
- 修复视图菜单中切换具体视图（如「树形视图」）会误将已展开的查看工具面板收起的问题。
- 修复 `Ctrl+Shift+F` 被 `Ctrl+F` 抢先匹配导致格式化快捷键失效的问题。

## 📦 下载

| 文件 | 说明 |
|---|---|
| **FileView_0.2.0_x64-setup.exe** | NSIS 安装包（推荐，含卸载项，一键清理注册表集成）|
| **fileview.exe** | 免安装单文件，双击即用 |

> 安装后在「设置 → 默认打开方式」中勾选需要的扩展名即可注册文件关联。

### 升级提示

- 直接覆盖安装即可，用户配置（主题、字号、最近文件等）自动保留。
- v0.2.0 扩展了可关联的扩展名列表，**升级后请在「设置 → 默认打开方式」重新勾选并点击「注册关联」**，以启用新增格式的默认打开方式。
- **首次启动不再自动注册任何文件关联**（此前版本会默认注册全部 73 种扩展名，
  可能已影响系统中 `.py` `.js` `.md` 等类型的默认打开方式）。
  如需恢复，请在「设置 → 默认打开方式」勾选后点击「注册关联」。

## 🔗 系统集成

- Windows 右键菜单「用 FileView 打开」（所有文件 / JSON / JSONL / 文件夹）。
- 默认打开方式（ProgID 注册 + `ms-settings:defaultapps` 一键跳转确认）。
- 开机自启（可选最小化启动）。
- 一键清理全部注册表写入，无残留。

## 🛠️ 开发

```bash
npm install
npm run tauri:dev     # 开发模式
npm run tauri:build   # 打包 exe + NSIS 安装器
npm test              # 前端纯逻辑测试（Node 内置 test runner）
cd src-tauri && cargo test   # 后端测试（注册表相关测试运行在沙箱中，不影响系统）
```

技术栈：Tauri 2 (Rust) + React 18 + Vite + Tailwind CSS。
